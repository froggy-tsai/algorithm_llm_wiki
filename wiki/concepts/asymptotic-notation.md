# 漸進分析與 Θ 記號

## 介紹

漸進分析用來描述輸入規模 `n` 增大時，執行時間函數的成長率。教材提出兩個重點：忽略機器相關常數，並觀察 `n → ∞` 時 `T(n)` 的成長。

投影片使用的記號在 PDF 視覺中為 `Θ`（文字擷取可能顯示成 Q）。對非負函數，教材定義：

`Θ(g(n)) = { f(n) : 存在正數 c₁、c₂、n₀，使得對所有 n ≥ n₀，0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n) }`

也就是當 `n` 足夠大時，`f(n)` 被 `g(n)` 的正比例常數上下界夾住。

## 教材範例

- `3n³ + 90n² − 5n + 6046 = Θ(n³)`：高次項決定漸進成長率，低次項及常數因子不改變 Θ 類別。
- 當 `n` 足夠大，Θ(n²) 演算法的成長率低於 Θ(n³) 演算法；教材也提醒實際工程仍需衡量其他目標。

## 插入排序的 Θ 分析

教材對插入排序給出的求和結論：

- 最壞情況（反向排序）：`T(n) = Σ(j=2..n) Θ(j) = Θ(n²)`。
- 平均情況（假設所有排列等可能）：`T(n) = Σ(j=2..n) Θ(j/2) = Θ(n²)`。

此頁的最好／平均／最壞情況定義見[演算法分析與執行時間](algorithm-analysis.md)。

## 注意

Θ 記號描述漸進成長率，不代表固定輸入上的實際秒數比較。教材指出小 `n` 的實務比較可能涉及工程考量；其 merge sort 與 insertion sort 的觀察記於 [Merge sort](../algorithms/sorting/merge-sort.md)，不將該觀察擴大解讀成通用門檻。
