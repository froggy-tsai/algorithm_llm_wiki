# 演算法分析與執行時間

## 介紹

演算法分析研究電腦程式的效能與資源使用。教材指出，演算法效能有助於理解可擴展性，也可能決定某項計算在實際上可行或不可行；演算法數學則提供描述程式行為的語言。

分析時間時，先以輸入規模 `n` 作為參數。即使輸入大小相同，實際執行時間也可能因輸入內容不同而改變，因此教材介紹三種情況：

- **最壞情況 (worst case)**：大小為 `n` 的所有輸入中，演算法所花時間的最大值。教材指出這是通常採用的分析方式。
- **平均情況 (average case)**：大小為 `n` 的所有輸入上的期望執行時間；需要對輸入的統計分布作假設。
- **最好情況 (best case)**：大小為 `n` 的輸入中最短的執行時間。教材提醒，單看最好情況可能造成誤導。

教材的機器無關分析重點是忽略依賴機器的常數，並觀察 `n` 趨近無限大時執行時間的成長率，詳見[漸進分析與 Θ 記號](asymptotic-notation.md)。

## 教材範例：插入排序

- 最壞情況：輸入為反向排序；教材以求和分析得到 Θ(n²)。
- 平均情況：假設所有排列等可能，教材以求和分析得到 Θ(n²)。
- 已排序輸入較容易排序，說明執行時間依輸入而異；本教材未在插入排序分析投影片中列出最好情況的漸進式，因此此處不補寫。

詳見[插入排序](../algorithms/sorting/insertion-sort.md)。

## 如何閱讀時間分析

1. 確認輸入規模參數，例如序列長度 `n`。
2. 確認分析的是最壞、平均或最好情況，以及教材採用的輸入假設。
3. 將執行時間表示成 `n` 的函數，再比較其漸進成長率。
4. 把漸進結論與實際工程觀察分開：漸進比較不等於對每個小輸入或每台機器的實測時間保證。
