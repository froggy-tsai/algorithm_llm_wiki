# VLSI 樹狀配置與 H-tree 嵌入

## 問題

教材提出：將有 `n` 個葉節點的完整二元樹嵌入網格，並使面積盡量小。它透過寬度 `W(n)`、高度 `H(n)` 及遞迴關係分析配置尺寸。

## 完整二元樹配置

教材列出：

- `H(n)=H(n/2)+Θ(1)=Θ(lg n)`
- `W(n)=2W(n/2)+Θ(1)=Θ(n)`
- 因此 `Area=Θ(n lg n)`

## H-tree 嵌入

教材圖示的遞迴關係為：

`L(n)=2L(n/4)+Θ(1)=Θ(√n)`

圖中因此得到面積 `Area=Θ(n)`。

## 限制

投影片提供的是問題、圖示及遞迴分析摘要，未完整說明網格模型、幾何合法性條件、邊界條件或建構配置的偽碼。本頁只記錄投影片明示的遞迴關係與漸進結論。
