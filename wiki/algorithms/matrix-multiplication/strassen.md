# Strassen 演算法

## 介紹

Strassen 演算法將 2×2 區塊矩陣乘法所需的 8 次遞迴子矩陣乘法減為 7 次，並以額外的加減法組合結果。對 `n × n` 矩陣，分割、遞迴計算 7 個 `(n/2) × (n/2)` 乘積，再組合輸出矩陣。

## 2×2 區塊公式

令 `A=[[a,b],[c,d]]`、`B=[[e,f],[g,h]]`。教材定義：

```text
P1 = a(f − h)       P5 = (a + d)(e + h)
P2 = (a + b)h        P6 = (b − d)(g + h)
P3 = (c + d)e        P7 = (a − c)(e + f)
P4 = d(g − e)

r = P5 + P4 − P2 + P6
s = P1 + P2
t = P3 + P4
u = P5 + P1 − P3 − P7
```

因此 `AB=[[r,s],[t,u]]`。投影片指出共有 7 次乘法、18 次加減法，且公式不依賴乘法的交換律。

## 執行時間

遞迴式：`T(n)=7T(n/2)+Θ(n²)`。

因 `n^(log₂ 7) ≈ n^2.81`，而 `n²` 為低階項，Master theorem Case 1 給出：

`T(n)=Θ(n^(lg 7))`。

這比[標準矩陣乘法](standard.md)的 `Θ(n³)` 漸進指數低。教材提到在當時機器上約 `n ≥ 32` 時會勝過普通演算法；投影片未提供具體機器或實驗方法，因此此數字只保留為教材中的實務觀察，不當作普遍門檻。

投影片另提及當時理論最佳結果的指數約為 `2.376`（投影片 45），未在本份材料中提供演算法細節或推導。

## 題目與解法

**題目**：計算兩個矩陣的乘積。

**解法**：採用上述 7 個區塊乘積與輸出組合式，遞迴計算較小矩陣乘積。
