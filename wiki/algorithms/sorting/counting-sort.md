# Counting sort（計數排序）

## 適用輸入

輸入陣列 `A[1..n]` 的每個鍵值都在 `{1, 2, …, k}` 範圍內。演算法另用計數陣列 `C[1..k]`，輸出到 `B[1..n]`。它不比較輸入元素彼此的大小，因此不是 comparison sort。

## 演算法

```text
COUNTING-SORT(A, B, n, k)
    for i = 1 to k
        C[i] = 0
    for j = 1 to n
        C[A[j]] = C[A[j]] + 1
    for i = 2 to k
        C[i] = C[i] + C[i − 1]
    for j = n downto 1
        B[C[A[j]]] = A[j]
        C[A[j]] = C[A[j]] − 1
```

各階段的意義：

1. 初始化計數。
2. 計算每個鍵值出現次數；此時 `C[i]` 是鍵值 `i` 的數量。
3. 累積計數；此時 `C[i]` 是小於或等於 `i` 的元素數量。
4. 從右向左掃描輸入，把元素放到輸出陣列中對應的最後位置，並遞減計數。

## 穩定性

從輸入右端向左放置，且每次遞減累積位置，使鍵值相同的元素保留原本相對順序。因此 counting sort 是 stable sort。教材範例輸入 `[4, 1, 3, 4, 3]`，輸出 `[1, 3, 3, 4, 4]`。

## 複雜度與限制

- 時間：`Θ(n+k)`。
- 輸出陣列為 `B[1..n]`，計數陣列為 `C[1..k]`。
- 當 `k=O(n)` 時，時間為 `Θ(n)`。
- 不適用於鍵值範圍相對輸入極大的情況時仍保證線性時間；本教材只給出上述 `n`、`k` 關係。

Comparison sorting 的 `Ω(n lg n)` 下界不限制 counting sort，因它不比較元素。下界見[比較排序的決策樹下界](../../concepts/comparison-sorting-lower-bound.md)。Counting sort 也作為[radix sort](radix-sort.md)每趟的穩定輔助排序。

## 題目與解法

**題目**：將鍵值範圍為 `1..4` 的輸入 `[4, 1, 3, 4, 3]` 排序。

**解法**：計數得各鍵值數量 `[1,0,2,2]`，累積後為 `[1,1,3,5]`，再由右至左放入 `B`，得到 `[1,3,3,4,4]`。
