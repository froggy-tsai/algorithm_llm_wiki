# 插入排序 (Insertion Sort)

## 介紹

插入排序維持一段已排序前綴，並依序取出下一個元素 `key`，將前綴中比它大的元素向右移，再把 `key` 放到空出的位置。教材以撲克牌整理手牌作為直觀類比（投影片圖示）。

## 偽碼

教材的 `INSERTION-SORT(A,n)`（陣列索引從 1 開始）：

```text
for j ← 2 to n
    key ← A[j]
    i ← j − 1
    while i > 0 and A[i] > key
        A[i + 1] ← A[i]
        i ← i − 1
    A[i + 1] ← key
```

## 運作步驟

每一輪開始時，`A[1..j−1]` 是已排序前綴。把 `A[j]` 暫存為 `key`，由右向左比較；凡是大於 `key` 的值就右移一格，最後將 `key` 放入正確位置。完成一輪後，已排序前綴增加一個元素。

### 教材範例

輸入：`[8, 2, 4, 9, 3, 6]`

依投影片的逐步示例，插入後的序列依序為：

`[8, 2, 4, 9, 3, 6]` → `[2, 8, 4, 9, 3, 6]` → `[2, 4, 8, 9, 3, 6]` → `[2, 4, 8, 9, 3, 6]` → `[2, 3, 4, 8, 9, 6]` → `[2, 3, 4, 6, 8, 9]`

輸出為非遞減排序結果：`[2, 3, 4, 6, 8, 9]`。

## 複雜度與輸入情況

- **最壞情況**：反向排序輸入；教材分析為 Θ(n²)。
- **平均情況**：假設所有輸入排列等可能；教材分析為 Θ(n²)。
- 教材指出已排序序列較容易處理，但未在本講義提供插入排序最好情況的明確 Θ 表達式。
- 教材描述插入排序對小 `n`「moderately so」，對大 `n`「not at all」；這是定性說明，沒有指定門檻。

背景見[演算法分析與執行時間](../../concepts/algorithm-analysis.md)及[漸進分析與 Θ 記號](../../concepts/asymptotic-notation.md)。

## 題目與解法

**排序題（教材定義與範例）**：給定數列，輸出包含相同元素且依非遞減順序排列的序列。教材範例輸入 `[8, 2, 4, 9, 3, 6]`，以本頁插入排序步驟得到 `[2, 3, 4, 6, 8, 9]`。

本講義未提供其他獨立程式題或測資，因此不另行新增題目。
