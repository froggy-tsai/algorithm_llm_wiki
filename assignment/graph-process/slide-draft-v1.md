## 逐張投影片草稿

### 1. 封面與學習目標

- **標題**：排序演算法：從比較排序到線性時間排序
- **副標**：看懂步驟、輸入條件與執行時間
- **目標**：追蹤排序步驟；辨認比較排序下界的範圍；依鍵值條件理解 counting／radix sort。
- **畫面**：六張小卡呈現六種排序方法；小助手說明「我們會看演算法怎麼移動資料」。
- **互動**：開始按鈕進入第 2 張。
- **來源**：封面和教學目標，不新增演算法事實。

### 2. 排序問題

- **標題**：排序要完成什麼？
- **核心內容**：輸入一個數列，輸出相同元素的非遞減排列。
- **範例**：`[8, 2, 4, 9, 3, 6] → [2, 3, 4, 6, 8, 9]`。
- **互動**：按一下「顯示結果」，再以排序後數列逐項標示順序。
- **來源**：EC-01；L1 投影片 4。

### 3. 比較排序的下界

- **標題**：只靠兩兩比較，最壞情況需要多少比較？
- **核心內容**：決策樹的一個內部節點代表一次比較；`n` 個互異元素可能有 `n!` 種排列，因此正確決策樹至少要有 `n!` 個葉節點。高度 `h` 的二元樹最多有 `2^h` 個葉節點，所以 `h ≥ lg(n!) = Ω(n lg n)`。
- **適用界線**：這個下界針對 comparison sorts；counting sort 不比較輸入元素，radix sort 以穩定排序處理位數，兩者不在此比較模型內。
- **互動**：輸入小型 `n`，顯示 `n!` 種排列及達到該葉數所需的最小整數樹高 `⌈lg(n!)⌉`；標示這是有限 `n` 的決策樹示例，漸進下界如上。
- **來源**：EC-02、EC-09；L5 投影片 2–10、28–29。

### 4. 插入排序

- **標題**：把下一個元素插入已排序前綴
- **核心內容**：維持已排序區間；從右向左比較，將較大的元素右移，再放入 key。
- **複雜度**：教材分析的最壞及平均情況均為 `Θ(n²)`；平均分析假設所有排列等可能。教材未給明確最好情況 Θ 式。
- **互動**：預設教材輸入 `[8, 2, 4, 9, 3, 6]`；可輸入短整數列並逐步前進／重設。每一步標示 key、比較位置和右移動作。
- **來源**：EC-03；L1 投影片 5–23。

### 5. Merge sort

- **標題**：分成兩半，排序後再合併
- **核心內容**：遞迴排序兩半；合併兩個已排序序列需 `Θ(n)`，遞迴式 `T(n)=2T(n/2)+Θ(n)`，總時間 `Θ(n lg n)`。
- **互動**：可輸入短整數列；按步驟顯示分割層級，再逐層合併已排序區塊。提供教材示意作為預設操作。
- **來源**：EC-04、EC-09；L1 投影片 24–50；L3 投影片 3–6。

### 6. Heapsort

- **標題**：用 max-heap 反覆取出最大值
- **核心內容**：先建 max-heap，再把根與 heap 尾端交換、縮小 heap、呼叫 max_heapify。教材給出建堆 `O(n)`、整體排序 `O(n lg n)` 上界。
- **互動**：使用教材陣列 `[4, 1, 3, 2, 16, 9, 10, 14, 8, 7]`，可逐步執行 heapify 和交換；畫面同步呈現 heap 範圍與已排序尾端。
- **來源**：EC-05、EC-09；L4a 投影片 3–26；L5 投影片 10。

### 7. Quicksort

- **標題**：pivot 如何改變切分？
- **核心內容**：先 partition，再遞迴排序 pivot 左右。固定取子陣列第一個元素為 pivot 時，教材列出已排序或反向排序輸入可能造成 `Θ(n²)` 最壞時間；平衡切分為 `Θ(n lg n)`。Randomized quicksort 的期望上界是 `O(n lg n)`，分析假設輸入元素互異、隨機選擇獨立。
- **互動**：以教材輸入 `[6, 10, 13, 5, 8, 3, 2, 11]`、首元素 pivot `6`，逐次顯示比較、交換和 pivot 歸位。之後用小測驗區分最壞情況與期望分析。
- **來源**：EC-06；L4 投影片 2–47。

### 8. Counting sort

- **標題**：鍵值範圍已知時，直接計數
- **核心內容**：輸入鍵值在 `1..k`；先計數，再累積位置，從右向左填入輸出以保留穩定性。時間 `Θ(n+k)`；當 `k=O(n)` 時為線性時間。
- **互動**：使用教材 `[4, 1, 3, 4, 3]`；逐步顯示頻數表、累積計數與輸出陣列。可改輸入，但超出 `1..k` 時顯示提示，不執行。
- **來源**：EC-07；L5 投影片 11–30。

### 9. Radix sort

- **標題**：從最低位開始，逐位穩定排序
- **核心內容**：LSD radix sort 每趟使用穩定排序。`b` 位元、每趟 `r` 位元時，教材時間式為 `Θ((b/r)(n+2^r))`；線性時間結論附帶教材所述的範圍與選擇條件。
- **互動**：預設教材數列 `[329, 457, 657, 839, 436, 720, 355]`；逐趟播放個位、十位、百位排序，前進／返回時顯示當前序列。
- **來源**：EC-08；L5 投影片 31–39。

### 10. 比較、選擇與小測驗

- **標題**：先看輸入條件，再比較排序方法
- **比較內容**：
  - Insertion sort：最壞與平均 `Θ(n²)`。
  - Merge sort：`Θ(n lg n)`。
  - Heapsort：教材給出 `O(n lg n)` 上界。
  - Quicksort：首元素 pivot 的最壞 `Θ(n²)`；randomized 期望 `O(n lg n)`，附分析假設。
  - Counting sort：`Θ(n+k)`；`k=O(n)` 時線性。
  - Radix sort：時間取決於位數、每趟基數和穩定輔助排序條件。
- **互動測驗**：
  1. 哪個下界只約束 comparison sorts？
  2. Counting sort 的線性時間需要什麼鍵值範圍條件？
  3. Radix sort 為什麼每趟需穩定排序？
- **來源**：EC-02、EC-05–EC-09；L5 投影片 9–10、28–39 及各演算法對應教材頁。
